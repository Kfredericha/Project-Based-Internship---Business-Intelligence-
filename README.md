# Project Based Internship - Bank Muamalat Business Intelligence Analyst

## Project Overview
This project serves as a comprehensive case study in Business Intelligence, where I role-played as a Business Intelligence Analyst for PT Sejahtera Bersama. PT Sejahtera Bersama is a retail company specializing in electronic products such as drones, robot kits, and eBooks.
The project involved building a structured data model and an analysis-ready master table using SQL (JOIN logic) to consolidate transactional data from customers, orders, products, and categories. This foundational work enabled the creation of an Annual Sales Analytics Dashboard designed to assist stakeholders in rapidly comprehending the company's health through multi-dimensional analysis across time, product categories, and regional performance.

## Dataset (Tables)
The dataset contains 4 tables:
- Customers
- Orders
- Product
- ProductCategory


## Project Objective
The primary goal of this project was to transform raw transactional data into actionable business insights through the following objectives:

- Data Consolidation: Utilize SQL JOIN logic to create a single, unified master table from disparate datasets (Customers, Orders, Products, and Product Categories) to simplify subsequent analysis and visualization.
- Performance Visualization: Develop a dashboard to visualize and analyze total sales, order quantities, and Average Order Value (AOV) across different dimensions.
- Pattern Identification: Identify key performance patterns, including seasonal sales fluctuations and regional demand concentration in specific cities like Washington, Houston, and Sacramento.
- Product Analysis: Distinguish between high-revenue generators (like Robots and Drones) and high-volume drivers (like eBooks and Training Videos) to understand their different roles in the business model.
- Strategic Recommendations: Uncover data-driven insights to support strategic decision-making, such as better-timed promotions and improved inventory planning.
